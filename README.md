# Syntecxhub Pandas CSV Reader & Basic Analysis

# Project Overview

This project demonstrates how to use Python and Pandas to read a CSV file, inspect the dataset, perform basic statistical analysis, filter data, select specific columns, and export filtered results.

# Technologies Used

- Python
- Pandas
- CSV
- Excel

# Dataset

The project uses a sales dataset containing:

- Date
- Product
- Category
- Quantity
- Price
- Revenue

# Operations Performed

1. Read the CSV file using Pandas.
2. Inspected the first and last rows using `head()` and `tail()`.
3. Checked dataset information and data types.
4. Calculated mean, median, minimum, maximum, and count.
5. Filtered Electronics products.
6. Selected specific columns.
7. Slic subsets 5 rows.
7. Exported filtered data to CSV.
8. Exported filtered data to Excel.

# Project Files

- `pandas_analysis.py` - Main Python analysis script
- `data/sales_data.csv` - Original sales dataset
- `output/filtered_sales.csv` - Filtered CSV result
- `output/filtered_sales.xlsx` - Filtered Excel result

# How to Run

```bash
python pandas_analysis.py
